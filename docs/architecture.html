02

Application Layer Map

외부 소스 → 계산 레이어(core) → 렌더링 레이어(ui) 순으로 데이터가 가공되는 3계층 구조입니다.

계층 (Layer) 주요 모듈 / 파일 역할 및 상세 설명
1. Sources price_data.py
naver_scraper.py
krx_listing.py 		외부 API 및 스크래핑을 통한 원천 데이터 수집 (TTL 5분~12시간 캐싱)
2. Core indicators.py
sentiment.py
scoring.py 		13개 객관지표 점수화, 종토방 감성분석 및 최종 비명지수/타점 계산
3. UI main_panel.py
chart.py
gauge.py 		Streamlit 화면 렌더링, Plotly 차트 시각화 및 타점 카드 표시
03

데이터 소스 이중화 전략 (Resilience Map)

외부 소스 장애 발생 시 시스템이 조용히 하위 단계(Fallback)로 전환되어 크래시를 방지합니다.

수집 대상 1차 소스 (Primary) 2차/3차 폴백 (Fallback)
상장 종목 목록 FinanceDataReader (StockListing) KRX KIND 직접 파싱 → 하드코딩 백업 20종목
개별 종목 가격 FinanceDataReader yfinance (.KS / .KQ 순차 시도)
시장 지수 FDR (KS11 / KQ11) yfinance (^KS11 / ^KQ11)
종토방 스크래핑 네이버 금융 실시간 파싱 Fail-safe (빈 리스트 반환으로 크래시 차단)
04

기술 스택 및 캐싱 정책

시스템 구동 환경과 Performance 최적화를 위한 st.cache_data TTL 설정.

기술 스택

프레임워크 Streamlit 1.40.1
데이터 처리 Pandas, NumPy, FDR, yfinance
스크래핑 requests, BeautifulSoup4
시각화 Plotly, Custom SVG

st.cache_data TTL

개별 종목 / 뉴스 10 분
종목토론방 / 지수 5 ~ 10 분
